# My GTD inbox (private)

Everything captured, one folder per item under `stuff/`. **[→ INBOX.md](INBOX.md)**
is the readable list (renders in the GitHub app on any phone).

Ways in:
- Email anything to the capture address (`rules.yaml → capture_address`)
- Gmail mail matching `rules.yaml` is pulled in every 30 minutes
- Tell Claude "add to my inbox: …"
- Laptop: `gtd capture …` then `gtd sync`
